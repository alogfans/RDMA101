# 第一篇：快速入门

程序通过网络发送数据，最终是为了让另一端使用这些数据。RDMA 把其中一部分搬运工作交给网卡，也要求程序提前准备好可访问的内存。

本篇从熟悉的 TCP socket 出发，随后检查实验环境，运行一个将字符串写入远端内存的程序。开始时只需要基本的 C/C++ 和 Linux 使用经验，暂时不用记住所有 Verbs 对象。
